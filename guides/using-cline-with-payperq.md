## What is Cline?

Cline is an amazing VS code extension that enables you to pair program with AI models by editing your codebase using natural language.
## Step by Step Set Up

### 1. Go to the VSCode extension marketplace and install

![PPQ API](/blog-images/using-cline-with-payperq/extension_marketplace.png)

### 2. Go to cline settings, select openAI compatible, and enter the following: 


![PPQ API](/blog-images/using-cline-with-payperq/cline_settings.png)
